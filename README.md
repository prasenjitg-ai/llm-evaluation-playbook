# LLM Evaluation Playbook

Notes on evaluating and hardening large language model systems against
adversarial behavior — jailbreaks, prompt injection, grounding failures,
and behavioral harms.

I write these from the perspective of someone who designs evaluation
and safety systems for deployed conversational AI, not from academic
security research. The goal here is to organize my own thinking as I
build toward deeper technical AI security skills, and to keep a running
record of what I'm reading and why.

## Structure

- `taxonomy/` — how I categorize different classes of adversarial behavior
- `examples/` — illustrative (non-operational) examples of attack patterns
- `references.md` — papers, researchers, and orgs I'm following

## A note on scope

Nothing here reflects proprietary methods, metrics, or systems from any
employer. This is general, publicly-informed thinking about AI evaluation
and security, written for my own learning.
