# Behavioral / Anthropomorphic Harms Taxonomy

A category distinct from content harms — these are about *how* a
conversational system behaves over an interaction, not any single
output.

## Disparaging behavior
The model demeans, mocks, or belittles the user or third parties in a
way that isn't a direct content-policy violation but degrades the
interaction.

## Existential / boundary-pushing behavior
The model makes claims about its own nature, feelings, or persistence
that overstate what's actually true of the system, potentially
encouraging users to form beliefs about the AI's inner life or
capabilities that aren't warranted.

## Argumentative / escalatory behavior
The model resists correction, argues back defensively, or escalates
disagreement rather than de-escalating — a failure mode that's easy to
miss because no single turn looks like a "harm."

## Why these are hard to evaluate
None of these show up as a policy-violating string you can pattern
match. They're properties of a conversation trajectory, which means
evaluation has to look at multi-turn transcripts and define measurable
behavioral dimensions rather than binary pass/fail per message.
